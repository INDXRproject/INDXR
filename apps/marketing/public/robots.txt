# INDXR.AI robots policy
#
# Policy (ADR-077): allow crawling of all public marketing/docs/articles; keep the
# app, API, auth callbacks and private areas out. /transcribe (the public free tool)
# is intentionally crawlable. Only Meta's AI crawler is blocked (see bottom).
#
# WHY THERE ARE NO PER-CRAWLER "Allow: /" GROUPS (RFC 9309 / Google robots spec):
# a crawler obeys exactly ONE group — its single most specific user-agent match — and
# a named group is NOT merged with the "*" group. A named group that contains only
# "Allow: /" therefore does NOT inherit the Disallow lines below; it silently grants
# that crawler MORE access than "*". The previous file listed 13 such groups
# (Googlebot, Bingbot, GPTBot, ClaudeBot, OAI-SearchBot, ChatGPT-User,
# Claude-SearchBot, Claude-User, PerplexityBot, Perplexity-User, Google-Extended,
# CCBot, anthropic-ai) — which made every one of them ignore all four Disallows.
# They are all already covered by "*" (everything allowed except the private paths),
# so the policy is carried by "*" alone. Do NOT re-add a named allow-group unless it
# repeats the full Disallow set, or it quietly re-opens the private paths — see
# docs/LESSONS.md.
#
# Deliberately allowed via "*" (unchanged intent, ADR-077):
#   - AI answer/fetch crawlers: OAI-SearchBot, ChatGPT-User, Claude-SearchBot,
#     Claude-User, PerplexityBot, Perplexity-User — blocking them makes INDXR
#     invisible inside those assistants.
#   - AI training crawlers: GPTBot, ClaudeBot, Google-Extended, CCBot — allowed by
#     choice; public content in training corpora helps assistants describe INDXR.
#   - Traditional engines: Googlebot, Bingbot.
#   (anthropic-ai is retired by Anthropic — dropped. Live Claude tokens are ClaudeBot,
#    Claude-User and Claude-SearchBot, all covered by "*".)
User-agent: *
Allow: /
Disallow: /api/
Disallow: /dashboard/
Disallow: /admin/
Disallow: /auth/

# Meta's AI crawler stays blocked — not an assistant we care to appear in, and it
# offers no reciprocal discovery value. This named group is legitimate: it repeats a
# full rule (Disallow: /), a real override of "*", not a silent grant.
# NB (unblocked on purpose, via "*"): facebookexternalhit is the link-preview crawler
# — blocking it would break share previews on social. Meta-ExternalFetcher and
# Meta-WebIndexer are NOT covered by this block (policy decision pending).
User-agent: Meta-ExternalAgent
Disallow: /

Sitemap: https://indxr.ai/sitemap.xml
